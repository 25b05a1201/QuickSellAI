
# QuickSell AI

QuickSell AI generates product descriptions for online sellers using a locally running open-weight AI model.

## Features
- Generate product descriptions
- Professional, Friendly and Catchy styles
- Copy generated text
- Local AI inference through Ollama

## Technology
- Python and Flask
- HTML, CSS and JavaScript
- Gemma 2B through Ollama

## Run locally
1. Install Python and Ollama.
2. Ensure the `gemma2:2b` model is available: `ollama pull gemma2:2b`
3. Install dependencies: `python -m pip install -r requirements.txt`
4. Run: `python app.py`
5. Open http://127.0.0.1:5000
